TNYPL ADMIN + EMAIL DEPLOYMENT

1. Run SUPABASE-SETUP.sql in Supabase SQL Editor.
2. Create the admin user and insert the user into public.admin_users.
3. Add Netlify environment variables listed in EMAIL-AND-ADMIN-SETUP.txt.
4. Deploy this package.

ADMIN URL:
https://tnypl.in/admin.html

FEATURES:
- Admin views registrations and private attachments
- Verify payment and age proof
- Mark eligible or rejected
- Select franchise and draft player
- Automatically email congratulations after drafting
- Registration confirmation email after successful submission
- CSV export
